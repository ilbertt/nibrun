Shiori saves bookmarks and, with them, a readable archive of the page — so a link that rots later
is still something you can read. See the
[documentation](https://github.com/go-shiori/shiori/blob/master/docs/index.md).

## Quick start

1. Click **Deploy on nibrun**. There is nothing to fill in.
2. Open the URL and sign in with the default account: `shiori` / `gopher`.
3. **Change that password straight away** in the settings page, then add your bookmarks.

There is a [browser extension](https://github.com/go-shiori/shiori-web-ext) for Firefox and Chrome
that saves straight to your own instance.
