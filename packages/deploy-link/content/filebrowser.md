File Browser puts a file manager in front of a directory: upload, download, preview, rename, move
and share, with users and permissions. See the
[README](https://github.com/filebrowser/filebrowser#readme).

## Quick start

1. Click **Deploy on nibrun**. There is nothing to fill in.
2. **Open the Logs tab to read the admin password.** File Browser generates one on first boot and
   prints it there.
3. Sign in as `admin`, change the password, and start uploading.

It is rooted at the volume, so what you put in it is still there after a redeploy — which also
makes it a way to look inside another app's `data/`.
