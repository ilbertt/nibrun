Memos is a note-taking server built around short entries rather than documents: write a card, tag
it, find it again by searching. The [Memos docs](https://usememos.com/docs) cover the rest.

## Quick start

1. Click **Deploy on nibrun**. There is nothing to fill in.
2. Open the URL and create the first account — it becomes the owner.
3. Write your first memo. Tag it with `#something` and the tag becomes a filter.
