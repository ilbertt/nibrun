Gotify takes messages over a simple HTTP API and pushes them to connected clients, with Android
and desktop apps to receive them. The [Gotify docs](https://gotify.net/docs/) cover the API and
the clients.

## Quick start

1. Choose the admin password on the deploy form. The username is `admin`.
2. Click **Deploy on nibrun**, open the URL and sign in.
3. Create an application to get a token, then POST your first message to `/message`.
