Gitea is a full Git forge — repositories, issues, pull requests, releases, a package registry and
Actions. The [Gitea docs](https://docs.gitea.com/) cover everything past the first push.

## Quick start

1. Click **Deploy on nibrun**. There is nothing to fill in.
2. Open the URL. The first screen is Gitea's own installer, and the account you create there is
   the administrator.
3. Create a repository and push to it over HTTPS.

## Good to know

This deploys a build put together for nibrun rather than an upstream release: it carries its own
`git` so that pushing works. Everything else is Gitea as documented.
