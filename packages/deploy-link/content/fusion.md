Fusion is a single-user feed reader with a responsive web UI and a Fever-compatible API, so mobile
clients like Reeder and Unread can read from it. See the
[configuration guide](https://github.com/0x2E/fusion#configuration).

## Quick start

1. Choose a password on the deploy form. It is the only thing between your feeds and everyone who
   reaches the URL, so the link does not carry one for you.
2. Click **Deploy on nibrun**, open the URL and sign in.
3. Add a feed, or import an OPML file from whatever you are leaving.
