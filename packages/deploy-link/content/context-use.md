Context Use is a knowledge base your agents read from and write to over MCP, with a passkey in
front of it. See the [README](https://github.com/massimoalbarello/context-use#readme).

## Quick start

1. Click **Deploy on nibrun**. There is nothing to fill in.
2. Open the URL and register a passkey — the first one registered is yours.
3. Point your agent at the MCP endpoint and let it start writing things down.
